# g1-console（日本語の概要）

Unitree G1 用の小さな Web コンソールです。ロボットの Jetson（PC2）上で動かし、状態の表示と、スマホやブラウザからの操作ができます。`--mock` を付けると、ロボットなしで全体を試せます。

このページは概要です。詳しい内容、オプション、API は英語版が正本です。→ [README.md](README.md)

> **警告（使う前に必ず読むこと）** このソフトは、実機に歩行指令、モード変更（ダンピングやゼロトルクを含む）、緊急停止を送れます。ソフトウェアの停止は、認証された安全機能では**ありません**。物理リモコンを手元に置き、2 人以上で、周囲を空け、最初はロボットを吊るすか座らせた状態で試してください。ほとんどの機能は実機で**未検証**で、画面に未検証と表示されます。自己責任で使ってください。無保証です（[LICENSE](LICENSE)）。

> **非公式** このプロジェクトは Unitree Robotics とは無関係で、承認も後援も受けていません。「Unitree」「G1」は各権利者の商標で、対応ロボットを示すためだけに使っています。

> **セキュリティ** サーバは平文の HTTP で、TLS はありません。ログイン Cookie には生のトークンが入り、起動ログにトークンが出ます。同じネットワークで通信を見られる人はトークンを取れます。`--no-auth` を付けると、ネットワーク上の誰でもロボットを動かせます。既定では `127.0.0.1` のみで待ち受けます。信頼できるネットワークでだけ使ってください。

## 主な機能

- 接続状態の表示（ハブ・Jetson・G1）と自動再接続
- モード切替（ダンピング、ゼロトルク、ロックスタンディング、座位、立ち上がりなど）。許可された遷移のみ
- 走行（ジョイスティックまたは矢印キー）。操作権（オペレータロック）が必要で、指令が途切れるとハブが止めます。緊急停止ボタンは常に表示
- アクション（手を振る、握手）。実機では未検証
- テレメトリ（電池、IMU、オドメトリ、29 関節など）、音声と LED
- カメラ映像と LiDAR 点群（既定では停止。ボタンで起動）
- 決められたコマンドの実行（`tasks/*.json`）、DDS のトピック確認
- 未検証の機能のボタンを押すと注意ダイアログを出し、既定は「キャンセル」
- `--mock`: ロボットなしで動かせる

## すぐ試す（ロボット不要）

```bash
python3 server.py --mock
```

<http://127.0.0.1:18790/> を開きます。表示は模擬で、ロボットには何も送りません。Python 3.8 以降のみで動きます。

## Jetson で動かす

```bash
python3 server.py --local                        # ループバックのみ、認証なし
python3 server.py --local --bind-iface wlan0     # wlan0 でも待ち受け（トークン必須）
```

手順の全体は [docs/JETSON_SETUP.md](docs/JETSON_SETUP.md)（英語）を見てください。

## 動作確認済みの環境

Unitree G1 29DoF、Jetson Orin NX、L4T R35.3.1、`ai_sport` 8.7.3.4。それ以外は未検証です。この環境でも、コンソール経由で検証済みの機能は一部だけです。未確認の項目は [docs/REAL_ROBOT_CHECKLIST.md](docs/REAL_ROBOT_CHECKLIST.md) にあります。

## 実機で使うときの注意

- コンソールと物理リモコンを同時に操作しない。リモコンの入力は SDK を通らず直接ロボットに届くため、画面と実際の状態がずれることがあります。
- Jetson 上の別プロセスがすでにロボットを制御していることがあります。モード切替が衝突する場合があります。
- 最初はロボットを吊るすか、周囲を空けて試す。ダンピングとゼロトルクで、立っているロボットは倒れます。
- 信頼できないネットワークに公開しない。
