## [0.1.0] - 2026-11-23

### Added
- Initial public version: web console and hub for the Unitree G1, with token
  authentication, motion control with emergency stop, mode and action control,
  tasks, DDS topic viewer, camera and lidar proxies, a mobile UI and a `--mock`
  mode that needs no robot.

### Notes
- Most functions are unverified on a real robot. The UI marks them and asks for
  confirmation before use. The verified environment is listed in the README.
